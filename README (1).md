# HRBA Interações Medicamentosas

**Protótipo de suporte à checagem de interações medicamentosas potenciais (IMPs)**  
Serviço de Traumatologia e Ortopedia – Hospital Regional do Baixo Amazonas (HRBA)

---

## Sobre

Ferramenta desenvolvida com base na **Padronização de Medicamentos do HRBA** e na lista oficial de **Medicamentos de Alta Vigilância (MAVs)** do hospital.

Objetivo: apoiar a equipe multiprofissional (farmacêuticos, médicos, enfermeiros e residentes) na identificação rápida de interações relevantes no contexto de pacientes internados em Traumato-Ortopedia.

---

## Características

- Lista de medicamentos extraída da padronização oficial do HRBA
- Foco nos fármacos mais utilizados no Serviço de Traumatologia e Ortopedia
- Classificação de gravidade (Contraindicado / Maior / Moderada / Menor)
- Mecanismo (farmacocinético ou farmacodinâmico)
- Contexto clínico específico de ortopedia/trauma
- Sugestões de monitoramento, alternativas disponíveis no hospital e manejo
- Aba com a lista completa de MAVs (Sonoridade Semelhante + Potencialmente Perigosos)
- Relatório para impressão / PDF
- 100% estático (HTML + CSS + JavaScript) – não precisa de servidor especial

---

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Selecione 2 ou mais medicamentos
3. Clique em **Verificar Interações**
4. Analise o resultado
5. Use o botão **Relatório** para imprimir ou salvar em PDF

---

## Como publicar (GitHub Pages)

1. Crie um repositório público no GitHub
2. Faça upload do arquivo `index.html` (e deste README, se desejar)
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`
4. Aguarde 1–2 minutos
5. O site ficará disponível em:  
   `https://seu-usuario.github.io/nome-do-repositorio/`
